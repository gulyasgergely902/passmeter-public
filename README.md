# PassMeter 🇺🇸

Welcome to the official support repository for **PassMeter**!

PassMeter is the ultimate tool to track passes and many more. Easily manage all your passes, tickets — whether time- or entry-limited — inside a clean iOS design.

---

## Support & Feedback

You can use this repository to:

* **Report a Bug:** Open a new issue with details about the problem.
* **Request a Feature:** Have an idea to make PassMeter better? Submit a feature request via Issues.

To open a new issue, navigate to the **Issues** tab and select **New issue**.

### Alternative Contact
If you don't have a GitHub account, you can reach out directly via email at:
📧 **[gulyas.gergely.alt@outlook.com]**

Make sure to include `PassMeter - Bug Report` or `PassMeter - Feature Request` as the subject.

---

*PassMeter processes and stores all your data locally on your device. No personal data is collected or shared.*

# PassMeter 🇭🇺

Üdvözöllek a hivatalos **PassMeter** támogatási oldalán!

A PassMeter a legjobb eszköz a bérleteid és jegyeid követéséhez - legyen az idő vagy alkalom alapú.

---

## Támogatás és Visszajelzés

Amennyiben segítségre van szükséged vagy pedig van egy jó ötleted az alkalmazás továbbfejlesztésére itt ezt elküldheted:

* **Hibajelentés:** Nyiss egy hibajegyet ahol leírod a problémát.
* **Új funkció igénylés:** Ha van egy jó ötleted, oszd meg!

Egy új jegy nyitásához menj az **Issues** fülre majd válaszd ki a **New issue** gombot!.

### Alternatív elérhetőség
Amennyiben nincs GitHub felhasználód, írj egy emailt:
📧 **[gulyas.gergely.alt@outlook.com]**

A levél tárgyába mindenképp kerüljön bele a `PassMeter - Bug Report` a hibajelentéshez vagy a `PassMeter - Feature Request` egy új funkció igényléséhez.

---

*A PassMeter minden adatod lokálisan, az eszközödön tárolja és kezeli. Személyes adatot nem gyűjt és oszt meg.*
